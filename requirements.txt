# yt-msd runtime dependencies (GUI Source Code/yt-msd-gui.pyw)
# Pinned to the versions verified working on the release machine (Python 3.14, Windows x64).
# Install with:  python -m pip install -r requirements.txt
#
# Notes:
#   - tkinter, ctypes, winreg, socket, zipfile are part of the Python standard library.
#   - VLC Media Player must be installed separately (the player needs libvlc.dll at runtime).
#   - ffmpeg/ffprobe must be installed separately (yt-msd takes them from PATH, and uses
#     them for format conversion and loudness normalisation):  winget install ffmpeg
#   - yt-dlp is NOT listed here on purpose: the GUI drives the yt-dlp installed on the
#     system through its command line instead of importing it, so yt-dlp stays current
#     without rebuilding yt-msd. Install or update it with:
#       winget install --id yt-dlp.yt-dlp -e
#       winget upgrade --id yt-dlp.yt-dlp -e
#     yt-msd does this itself on the first run, and offers the update when GitHub says a
#     newer yt-dlp exists. A yt-dlp.exe placed next to the program or anywhere on PATH
#     works too.
